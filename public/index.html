    棋譜

    このサイトについて

    将棋オンライン道場は、BusinessMaker が個人で運営する無料のオンライン将棋道場です。対局は回数無制限・無料です。

    利用のルール

    • レート対局で、AIや他人の助けを借りて指すことは禁止です。
    • 暴言・荒らし・なりすましは禁止です。チャットの名前を押すと、ミュート・通報ができます。
    • 運営は予告なくサービス内容を変更・停止することがあります。

    保存するデータ

    名前、レーティング、戦績、棋譜、チャット通報の内容を保存します。本人確認のための番号は、ブラウザ内とサーバー（暗号化した形）に保存します。

    使用しているソフトウェア

    AI（ブラウザ内で動作）に Fairy-Stockfish（GPL-3.0、作者 Fabian Fichter ほか）を改変せずに使用しています。ソースコードは上記リンクから入手できます。このサイトのソースコードは GitHub で公開しています。
